# Carom

Carom is a fast, top-down paddle duel where paddle movement adds spin to every return. Curve the ball around the central gates, catch the walls for bank shots, and outscore your opponent in solo or local versus play.

## Run it

```sh
npm ci
npm run dev
```

Open the address Vite prints. Create a static production build with:

```sh
npm run build
```

The complete site is emitted to `dist/` and can be served by any static host.

## Controls

- Player one: `W` / `S`
- Player two (Versus): `↑` / `↓`
- Select: `Enter` or `Space`
- Pause / back: `P` or `Escape`
- Mute: `M`

In Solo, either player's movement keys control the left paddle. Move your paddle as you make contact to bend the ball's path.
